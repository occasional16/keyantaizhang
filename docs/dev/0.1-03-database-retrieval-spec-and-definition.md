## 1. 结论与设计

### 1.1 实验室官方机构特征词映射
为确保检索无遗漏，各大数据库检索时必须覆盖实验室历史更名演进与院系归属：
- **现名**：`高端装备界面科学与技术全国重点实验室` / `State Key Laboratory of Tribology in Advanced Equipment`
- **原名**：`摩擦学国家重点实验室` / `State Key Laboratory of Tribology` / `SKLT`
- **院系**：`清华大学机械工程系` / `清华大学机械系` / `Department of Mechanical Engineering, Tsinghua University`

### 1.2 检索与处理全流程闭环
```text
[ 教师名单 config/teachers_profile.xlsx ]
        │
        ▼ (生成/配置)
[ 官方检索式 (WOS / EI / CNKI / Scopus) ] ──> [ 导出标准文件放入 raw_data/ ]
                                                        │
                                                        ▼
                                    [ 科研台账本地一键清洗/消歧/去重 ]
                                                        │
                                                        ▼
                                    [ 直出 papers_final_merged.xlsx ]
```

- **实施分工**：
  - 长期实操指南已落实在 [`docs/DATABASE_RETRIEVAL_GUIDE.md`](../DATABASE_RETRIEVAL_GUIDE.md)，指导日常操作；
  - 本文专注于核心学术边界判定与业务规则讨论。

## 2. 待确认与讨论事项（关键业务定义）

### 2.1 “SCI / EI / 中文核心”的精确判定边界
1. **SCI 的定义范围**：
   - 是否严格限定为 Web of Science 核心合集中的 **SCIE (Science Citation Index Expanded)**？
   - WOS 核心合集中的 **ESCI (Emerging Sources Citation Index)** 是否纳入 SCI 统计？
2. **EI 的收录范围**：
   - 是否严格区分 **JA (Journal Article, 期刊论文)** 与 **CA (Conference Article, 会议论文)**？（目前台账是否仅统计 JA？）。
3. **“中文核心”的判定基准**：
   - 国内主要核心体系包括：**北大中文核心**、**CSCD (中国科学引文数据库)**、**CSSCI (南大核心)** 及 **中国科技核心**；
   - 实验室统计是以**北大核心**为准，还是**CSCD 核心库**为准？
   - **操作策略建议**：是在知网检索时勾选【核心期刊】+【CSCD】前置过滤导出，还是在本地维护 `config/journal_if.xlsx` 进行期刊名称字典匹配？

### 2.2 机构署名与成果归属认领规则
1. **纯院系署名归属**：论文作者单位仅写了 `清华大学机械工程系`（漏写国重/全重实验室），只要作者在 `teachers_profile.xlsx` 中，是否 100% 认领入库？
2. **作者角色要求**：成果认领是否对作者排位有要求（如必须是第一作者/通讯作者，还是任意位次合作论文均可认领）？（当前系统逻辑为任意位次只要有本组成员即认领）。

### 2.3 检索式自动生成辅助工具
- 是否需要在 Excel 控制台或后台脚本中增加**“一键复制当前教师检索式”**辅助功能（根据 `teachers_profile.xlsx` 自动拼接 WOS / EI / CNKI 官方高级检索字符串）？

## 3. 开发者操作与测试指南

1. 参考 [`docs/DATABASE_RETRIEVAL_GUIDE.md`](../DATABASE_RETRIEVAL_GUIDE.md) 在 WOS、EI、知网进行一次小规模年份抽样检索测试；
2. 将导出的 `WOS.txt`、`EI.xlsx`、`CNKI.xls` 放入 `raw_data/`；
3. 点击工作台运行全流程，观察 `papers_final_merged.xlsx` 中 Sheet 1 与 Sheet 2 的分类与作者匹配效果；
4. 针对上述第 2 节的定义边界给出指导反馈。
