## 2. 待确认事项：业务定义、背景解释与推荐方案

### 2.1 “SCI / EI / 中文核心”的精确判定边界

#### 1. SCI 的收录范围（SCIE vs ESCI）
- **背景与解释**：Web of Science 核心合集包含 SCIE（自然科学引文索引扩展版）与 ESCI（新兴资源引文索引）。国内高校科研考核与学科评估中的“SCI 论文”传统上特指 **SCIE** 来源期刊；ESCI 期刊未进入正式 JCR 核心分区，通常不计入正式 SCI 绩效。
- **推荐方案（Recommended）**：**严格限定为 SCIE**。检索与统计时排除 ESCI；若在结果中出现，在台账中单列为 `ESCI` 标签，绝不混淆计入 `SCI`。

#### 2. EI 的收录类型（JA 期刊 vs CA 会议）
- **背景与解释**：EI Compendex 严格区分 **JA (Journal Article, 期刊论文)** 与 **CA (Conference Article, 会议论文)**。在重点实验室与机械工程学科评估中，EI 期刊 (JA) 具有与 SCI 相当的重要权重，而会议论文 (CA) 水平参差不齐，通常单独统计或不纳入成果台账。
- **推荐方案（Recommended）**：**默认仅统计 EI JA (期刊论文)**。在 EI 检索或台账去重时过滤 CA，或在收录类型中明确细分标注为 `EI (JA)` 与 `EI (CA)`。

#### 3. “中文核心”的认定标准与提取策略
- **背景与解释**：国内核心体系主要包含北大《中文核心期刊要目总览》与中科院《中国科学引文数据库 (CSCD)》。知网全量导出包含大量普通学术期刊、会议与硕博学位论文，若无前置或后置过滤，无法直接视为核心。
- **推荐方案（Recommended）**：**知网检索前置过滤 + 标签标注为中文核心**。在知网检索端勾选【核心期刊】（北大核心）与【CSCD】来源类别后导出，确保源头纯净；台账收录标签统一标注为 **`中文核心`**。

---

### 2.2 机构署名与成果归属认领规则

#### 1. 论文仅署名“清华大学机械工程系”的归属
- **背景与解释**：实验室依托清华大学机械工程系建设，部分师生因期刊版面限制或投稿习惯，单位仅填写了 `清华大学机械工程系`，未显式写出实验室名称。若强制要求必须带实验室字样，会导致大量真实科研产出被遗漏。
- **推荐方案（Recommended）**：**以人为本，全量认领**。只要论文作者包含 `teachers_profile.xlsx` 中的本组师生，且单位属于清华大学（含机械系），一律认领计入本组入库台账（Sheet 1）。

#### 2. 作者排位与贡献度要求
- **背景与解释**：年终考核与职称评定通常要求第一作者或通讯作者，但课题组总台账的核心目的是“摸清团队学术家底”，全面掌握团队参与的所有产出。
- **推荐方案（Recommended）**：**总台账全量收录，不设排位门槛**。只要包含本组成员即纳入台账；后续版本可在数据列中扩展标注该老师的具体作者位次（如第一作者/通讯作者/共同作者）。

---

### 2.3 检索式自动生成辅助功能
- **背景与解释**：手动拼接几十位教师的中英文拼音、别名与布尔逻辑（`OR` / `AND`）极其繁琐且极易出错。
- **推荐方案（Recommended）**：**在系统中提供检索式生成辅助能力**。根据 `teachers_profile.xlsx` 中的名单，一键生成符合 WOS、EI、知网官方语法的高级检索字符串，方便科研秘书直接复制粘贴。
