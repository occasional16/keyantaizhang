## 1. 结论与设计

### 1.1 实验室官方机构特征词映射
在各大数据库进行机构（Affiliation / Address）检索时，必须统一覆盖以下实验室历史沿革与官方缩写：
- **现名**：`高端装备界面科学与技术全国重点实验室` / `State Key Laboratory of Tribology in Advanced Equipment`
- **原名**：`摩擦学国家重点实验室` / `State Key Laboratory of Tribology` / `SKLT`
- **依托单位（辅助检索）**：`清华大学机械工程系` / `Department of Mechanical Engineering, Tsinghua University`

### 1.2 检索与认领的最佳实践分工闭环
```text
[ 官方检索式: 仅按国重机构 (WOS / EI / CNKI) ] ──> [ 导出整室全量数据放入 raw_data/ ]
                                                                │
[ 课题组教师名单 config/teachers_profile.xlsx ] ───────────────┼──> [ 本地台账自动消歧认领/去重 ]
                                                                │                   │
                                                                ▼                   ▼
                                                [ Sheet2: 全室排除成果备查 ]  [ Sheet1: 课题组入库成果 ]
```

- **实施分工**：
  - 各大数据库仅按机构检索的高级检索式及导出 SOP 维护于长期文档 [`docs/DATABASE_RETRIEVAL_GUIDE.md`](../DATABASE_RETRIEVAL_GUIDE.md)；
  - 本文档固化已获批准的收录口径、认领规则与边界定义。

## 2. 确认决策项：业务定义与规则落地

### 2.1 “SCI / EI / 中文核心”的精确判定口径（已获批）

1. **SCI 收录口径（严格限定为 SCIE）**：
   - **规则**：仅统计 Web of Science 核心合集中的 **SCIE (Science Citation Index Expanded)** 来源期刊；
   - **处理**：检索与统计时排除 ESCI；若在结果中出现则单列为 `ESCI` 标签，不混入正式 `SCI` 成果。

2. **EI 收录口径（默认仅统计 EI JA 期刊）**：
   - **规则**：默认仅统计 EI Compendex 中的 **JA (Journal Article, 期刊论文)**；
   - **处理**：在 EI 检索与台账处理中过滤会议论文 (CA)；如需区分则明确标注为 `EI (JA)` 与 `EI (CA)`。

3. **中文核心认定口径（前置过滤 + 标注核心）**：
   - **规则**：知网检索时在界面勾选【核心期刊】（北大核心）与【CSCD】来源类别后导出；
   - **处理**：台账系统将知网导入成果统一标注为 **`中文核心`**。

---

### 2.2 机构署名与成果归属认领规则（已获批）

1. **机构署名范围（暂时严格限定标注国重）**：
   - **规则**：当前版本**仅统计作者单位明确标注了国重/全重实验室的论文**（即包含 `高端装备界面科学与技术全国重点实验室` / `摩擦学国家重点实验室` / `SKLT`）；
   - **处理**：若论文仅标注 `清华大学机械工程系` 但未写出国重/全重实验室，暂不自动认领进入入库大表（分流至 Sheet 2 供核对）。

2. **作者排位与贡献度要求（全量认领，位次后续扩展）**：
   - **规则**：总台账面向团队学术家底摸底，**不设作者排位门槛**；
   - **处理**：论文作者中只要包含 `teachers_profile.xlsx` 中的本组师生，一律全量认领；具体作者位次提取（一作/通讯）在后续版本中扩展。

---

### 2.3 检索式组织方式（已获批）

- **规则**：暂不在代码或控制台中开发自动生成检索式功能；
- **处理**：统一以 [`docs/DATABASE_RETRIEVAL_GUIDE.md`](../DATABASE_RETRIEVAL_GUIDE.md) 中维护的各数据库检索式为准，供开发者测试与使用。

## 3. 开发者操作与测试指南

1. 参考 [`docs/DATABASE_RETRIEVAL_GUIDE.md`](../DATABASE_RETRIEVAL_GUIDE.md) 在 WOS、EI、知网进行检索与导出测试；
2. 将导出的 `WOS.txt`（SCIE）、`EI.xlsx`（JA）、`CNKI.xls`（核心+CSCD）放入 `raw_data/`；
3. 点击工作台运行全流程，核对 Sheet 1（国重入库）与 Sheet 2（排除明细）的准确性；
4. 测试完成后反馈实际效果，以便进入后续代码优化阶段。
