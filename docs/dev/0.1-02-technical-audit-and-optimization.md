## 1. 结论与设计

### 1.1 核心问题诊断与优化策略
基于 `GPT-1/2/3` 的源码级审计，当前系统在完成“100% 真实动态统计”与“双工作表交付”后，仍存在 6 项影响数据准确性与系统健壮性的技术缺陷。推荐按以下数据处理流进行针对性重构与加固：

```text
[ 多源抽取 Mod2 ] ──> [ 严格DOI清洗 + Scopus补齐 ] ──> [ 标题+年份双键去重 ]
        │
[ 师生档案 Mod1 ] ──> [ 生僻字报警 + 手工别名列 + 缩写重名防覆盖 ] ──> [ 精准/高置信消歧认领 ]
        │
[ 成果交付 Mod2 ] ──> [ CNKI分类纠正 + Sheet2带原因追溯 + 健壮错误捕获 ] ──> [ 交付大表 ]
```

### 1.2 关键模块优化方案

#### 1. DOI 深度归一化与标题联合去重 (`Mod2_CleanRawData.bas`)
- **DOI 标准化**：彻底剥离 `https://doi.org/`、`http://dx.doi.org/`、`doi:` 及末尾空白/标点，统一为标准 `10.xxxx/...` 小写主键。
- **二级标题去重加固**：保留拉丁/希腊字母与数字，二级去重升级为 **`纯净标题 + 出版年份`** 联合校验，防止无 DOI 场景下的跨年异文误并。

#### 2. 师生拼音引擎防冲突与生僻字容错 (`Mod1_TeacherPinyin.bas` & `config`)
- **别名防覆盖与冲突告警**：重构字典存储结构为 `alias -> List<Name>`。对于同组内重名缩写（如“王军”与“王静”均产生 `Wang, J`），降级该冲突缩写的自动匹配权限，并在控制台提示冲突。
- **生僻字与自定义别名支持**：在 `config/teachers_profile.xlsx` 中新增可选列 `自定义英文别名 (Aliases)`；`GetCharPinyin` 遇未知字符时在控制台高亮报警，避免静默遗漏。

#### 3. 中文文献分类纠偏与预留字典映射 (`Mod2_CleanRawData.bas`)
- **纠正“CNKI = 中文核心”的逻辑谬误**：知网导出源默认收录标签调整为 **`中文期刊`**（或 `知网收录`）。
- **预留扩展接口**：读取 `config/journal_if.xlsx` 中的核心期刊目录，命中者再晋升标注为 `中文核心` / `CSSCI` / `CSCD`。

#### 4. 补齐 Scopus 官方数据抽取引擎 (`Mod2_CleanRawData.bas`)
- 实现 `IngestScopusData` 函数，解析 `raw_data/scopus.csv`（抽取 `Title`, `Source title`, `Volume`, `Issue`, `Authors`, `DOI`, `Year`, `Date`），消除“文档超前于代码”的断层。

#### 5. 交付大表 Sheet 2 增加“排除原因”列与可观察性 (`Mod0` & `Mod2`)
- 在 `papers_final_merged.xlsx` 的 Sheet 2 增加第 H 列 **`排除/待核原因`**（如 `未匹配到本组成员`、`出版年份超期: 2024`、`关键字段缺失`），大幅提升科研秘书核查体验。
- 移除跨模块的盲目 `On Error Resume Next`，采用结构化局部容错并记录具体失败文件。

## 2. 待确认事项

1. **CNKI 默认标签命名**：知网未匹配到核心期刊字典时，收录类型标签建议统一为 `中文期刊`（可选：`中文`、`CNKI`）。
2. **Scopus 支持排期**：是否在本次 0.1.x 优化中直接补齐 `IngestScopusData`？（推荐：直接补齐，使文档与代码对齐）。
3. **同名缩写认领策略**：当组内多人缩写冲突（如 `Wang, J`）且论文作者仅有该缩写时，是标记为“待确认”进入 Sheet 2，还是将冲突人名联合列出？（推荐：归入 Sheet 2 并标注“作者缩写重名需确认”）。
